Excalidraw Guide

Navigate from
page to page

Use Frames as pages, then link between them using element links — no account needed.

Step-by-step walkthrough
1
Create your frames
Each frame = one page
Press F to activate the Frame tool, then drag on the canvas to draw a frame. Repeat to create a second frame. Double-click the frame name to rename it (e.g. "Home", "About").

2
Add a button on Frame 1
This becomes the clickable link
Press R to draw a rectangle inside Frame 1. Double-click it and type a label like "Go to Page 2 →". This shape will be your navigation button.
Frame 1
Go to Page 2 →
Style your button however you like — fill color, rounded corners, any shape works as a link.
3
Select the button & open link dialog
Ctrl/⌘ + K shortcut
Click to select your button shape, then press Ctrl + K on Windows or ⌘ + K on Mac. A link input box will appear above the element.
Alternatively: right-click the element → Add link from the context menu.
4
Link to Frame 2
Internal element or external URL
In the link dialog you have two options:
Option A — Internal
Click the canvas icon in the dialog, then click on Frame 2. The view will jump to Frame 2 when clicked.
Option B — External URL
Paste any URL and press Enter. Clicking the element opens that page in a new browser tab.
A small chain-link icon appears on your element once the link is attached successfully.
5
Click to navigate
Hold Ctrl/⌘ and click
Hold Ctrl (Windows) or ⌘ (Mac) and click the linked element. The canvas will smoothly pan and zoom to show Frame 2.

Bonus tip
Presentation mode

Present frames like slides

Click Present in the bottom-right corner of Excalidraw to enter full-screen slideshow mode. Use arrow keys to move between all frames in order — no clicking links required.
